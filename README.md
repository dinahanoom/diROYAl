# diPWAL — The Young Royals

Website statis responsif tentang Prince George, Princess Charlotte, dan Prince Louis of Wales.

## Isi
- `index.html`
- `style.css`
- `script.js`

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload ketiga file tersebut ke root repository.
3. Masuk ke **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan, lalu tunggu GitHub Pages membuat URL situs.

## Catatan gambar
Semua foto yang digunakan website ini dibundel secara lokal di folder `images/`, sehingga GitHub Pages tidak bergantung pada hotlink gambar eksternal.
